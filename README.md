# TopazCraft

Мод для Minecraft (Fabric), добавляющий один декоративный светящийся блок — **Топазовый блок**.

Назначение: строительный блок, который освещает помещение без факелов и красиво смотрится в постройках.

## Совместимость

| Компонент | Версия |
|---|---|
| Minecraft | 1.20.1 |
| Fabric Loader | 0.15.11 |
| Fabric API | 0.92.2+1.20.1 |
| Java | 21 |

Другие версии не проверялись.

## Объект

- Название: **Топазовый блок**
- Идентификатор: `topazcraft:topaz_block`
- Команда получения: `/give @s topazcraft:topaz_block`
- Творческий инвентарь: вкладка «Строительные блоки»

## Свойства объекта

| Параметр | Значение | Назначение |
|---|---|---|
| `strength(3.0f, 6.0f)` | прочность 3, взрывоустойчивость 6 | как у железного блока: надёжный строительный материал |
| `luminance(8)` | свет уровня 8 из 15 | освещает помещение, но слабее факела (14) и светокамня (15) |
| `requiresTool()` | нужна кирка не ниже каменной | блок нельзя быстро добыть голой рукой; без кирки предмет не выпадает |

## Рецепт

Форменный рецепт (`minecraft:crafting_shaped`), результат — 1 блок:

```
А З А        А — осколок аметиста (minecraft:amethyst_shard)
З Д З        З — золотой слиток   (minecraft:gold_ingot)
А З А        Д — алмаз            (minecraft:diamond)
```

Обоснование: блок светится и прочен, как железный, поэтому стоит заметно дороже обычного
строительного блока. Золото и аметист соответствуют «драгоценному» облику, алмаз в центре
делает блок редким. Стоимость: 4 золотых слитка, 4 осколка аметиста, 1 алмаз.

## Дополнительное поведение

**Сценарий (3 шага):**
1. Исходное состояние: Топазовый блок установлен в мире, в основной руке игрока ничего нет.
2. Действие: игрок нажимает правой кнопкой мыши на Топазовый блок.
3. Результат: в чате появляется сообщение «Топаз тёпло светится в ваших руках.».

**Отличие нашего объекта от остальных:** обработчик проверяет `state.isOf(ModBlocks.TOPAZ_BLOCK)`.
Для всех остальных блоков возвращается `ActionResult.PASS`, и игра работает как обычно.
Если в руке есть предмет (например, блок для строительства), обработчик не вмешивается.

## Установка

1. Установите Minecraft Java Edition нужной версии и Fabric Loader (см. «Совместимость»).
2. Установите Fabric API в папку `mods`.
3. Поместите JAR мода (`topazcraft-<версия>.jar` из `build/libs`) в папку `mods`.
4. Запустите игру с профилем Fabric и создайте мир.
5. Проверьте, что блок доступен во вкладке «Строительные блоки» или командой `/give`.

## Сборка из исходников

```
.\gradlew.bat clean build
```

Готовый файл: `build/libs/` (основной JAR, без суффиксов `-sources` и `-dev`).

## Известные ограничения

- Реализован один блок, без собственных звуков и анимаций.
- Сообщение при использовании блока выводится только в чат.
- Работа проверена только на версиях из таблицы совместимости.
